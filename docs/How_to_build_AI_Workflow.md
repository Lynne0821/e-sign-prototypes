# 如何搭建个人 AI 工作流

产品经理的日常，往往在“接杂乱需求、理业务逻辑、画流程图、写 PRD、出交互原型”的无限循环中度过。其中大量时间被消耗在排版、画图和填模板等“体力活”上。

如何从繁杂中抽身？答案是**拆解工作，并将高频节点“Skill 化（技能化）”**。

### 1. 拆解日常工作，识别 AI 场景
我们将需求落地拆为三步，只要具备“固定输入+标准输出”的环节，都能交给 AI：
*   **输入期（资料解析）**：把业务方丢来的零散聊天记录、Excel 模板，让 AI 提炼成结构化的业务背景和痛点。
*   **分析期（逻辑推演）**：让 AI 帮你梳理业务规则，穷举边界异常（Edge Cases）和状态流转。
*   **产出期（文档与原型）**：让 AI 直接输出标准格式的 PRD、Mermaid 流程图，甚至高保真 HTML 前端原型。

### 2. 怎么把操作变成专属 Skill？
不要每次都重新调教 AI，把好用的 Prompt 固化成可复用的“技能”：
*   **第一步：提炼标准 Prompt**。明确定义**角色**（如：资深后台PM）、**约束**（如：必须包含状态机、不准捏造字段）、**输出结构**（如：按指定模板分点输出）。
*   **第二步：文件化封装**。将这段长 Prompt 保存为一个独立的 Markdown 文件（例如 `prd-generator.md`），并在文件头部写上简短的触发词或描述。
*   **第三步：挂载到 AI 工具**。将文件存入你的 AI 工作台（如 Cursor 的 `.cursor/skills` 目录）或个人代码仓库。

下次遇到新需求，只需一句“触发 PRD 生成技能”，AI 就会精准调取你的私人标准，瞬间产出高质量交付物。把重复的套路变成 Skill，把精力留给真正的业务思考！
